Bio Tank

I've always liked coding in behaviors, not hard coding. And emergent behavior is so fun to create. Here I started with some simple bubbles that merge on contact, then added small bubble munchers and then larger meat eaters. There is some emergent behavior here, the munchers sometimes almost flock as they go after the same bubbles but keep away from each other. The ecosystem is also self regulating--too many munchers and the eaters grow numerous, but then they eat all the munchers and starve out. It looks pretty too. Hit [tab] to see some debug info and creature stats.

All We Are Is Grok in the Wind

I like white noise machines, but custom noise machines are better. I tried to make one with Grok. He's pretty good at knowing technical stuff, including HTML Audio context. He whipped me up some white noise easily, and then I had him make 16 bands of playback using a band pass filter node to customize each channel freqency. Each band also has it's own gain, and for fun each has an LFO that can slowly modify the gain over time.
It sounds pretty good, although messing with the Q param of the band filter is tricky, as sound is weird and the Q should probably get wider for the lower freqs. Also you don't really get much bass from white noise so the bottom freqs need some more kick. Maybe a real audio engineer would know what to do, but I think Grok and I did a pretty decent job.
I've been using it as my windy background for a few days and it's pretty satisfying. I've loaded my setup as the default. There's also a randomize button and you can save your favorite settings to json files.
